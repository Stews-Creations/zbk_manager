Choose the world to host

Pick the folder that contains level.dat, usually inside .minecraft/saves.

      Datapacks in this world

        The world must already contain its datapacks and structures, whether the structures are inside a datapack or saved in the world. The server runs a copy, so your save is never changed.

        Resource pack

        Minecraft loads a world's pack only in singleplayer. A server never sends it, so this app shares it with players as a download.

        Download options
